## 主要数据特征解释

- 路线是首要成本：移动占总时间 70.25%，且移动距离与总时间相关系数为 +0.856。
- 无信号仍是主要动作形态：平均 440.0/485.7 次测量无信号。结合题目规则推断，未占用频道和定向半平面外观测会持续产生这种成本，不能靠一次负观测安全删除频道。
- 首次清除呈右偏：中位数 768.3 s，均值 1099.6 s，P95 2576.7 s；少数迟迟无法形成精确交会的案例拉高均值。
- 源越多，测量反而越少：10 源平均 543.7 次，16 源平均 402.2 次。原因包括未占用频道更少；达到题目上限 16 后策略还能立即结束剩余搜索，因此 16 源组总时间出现明显下降。
- 定向源占比升高会增加难度：高定向占比组比低占比组平均多用 592.7 s、多测 31.3 次，首次清除晚 508.2 s。
- 总时间分布相对集中，变异系数为 6.72%；不过最慢案例仍比均值高 19.9%，尾部主要同时具有长路线、较多测量和较多定向失锁。

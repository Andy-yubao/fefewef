# Paper figure assets

This directory separates paper-figure source material from the current `task1-4` implementation.

- `originals/`: archived source images, scripts, and provenance notes.
- `paper_figures/`: assets currently suitable for paper layout or generated candidates awaiting review.
- `prompts/`: prompts for image-generation work.
- `source_manifest.csv` and `source_manifest.md`: source index.
- `remaining_tasks.md`: follow-up redraw and review work.

The archive was created from the repository and the three supplied paper PDFs. No business logic in `task1-4` was modified.

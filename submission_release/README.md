# Q1--Q4 提交支撑项目

本目录包含本项目四个问题的正式实现、实验数据、结果快照、测试和复现入口，用于保存一个可独立检查的提交版本。

## 项目内容

- `task1/`：硬可行域、圆盘裁剪、区域直径和最小包围圆。
- `task2/`：第二检测点选择策略及其批量实验，包含 GDOP Mean、Geometry、FIM E 和 Random 四种策略。
- `task3/`：七点覆盖、路线规划、在线控制和规模化验证。
- `task4/`：双环点位、清除策略、局部模拟器及受控实验。
- `experiments/`：本地模拟评测机。
- `results/`、各任务下的 `results/`：实验冻结结果和验证数据。
- `paper_appendix/`：由本目录正式源代码整理出的代码附录文本。
- `verify.py`：统一检查四个问题的关键计算和冻结结果。

## 目录约定

正式源代码、实验配置、数据和测试均保存在本目录内；缓存、虚拟环境和临时运行输出不属于项目内容。各任务的 README 提供对应模块的局部说明。

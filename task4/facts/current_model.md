# Q4 最终模型：adaptive_double_ring_clear_probe

## 1. 总体结构

模型分为“发现/安全收尾层”和“效率层”。策略只经四个官方接口取得响应，不读取真值的数量、位置、类型、半径或朝向；本地真值仅在运行结束后评分。

未知频道维持未见、活跃、已定位、已清除等状态。正示向观测被表示为带±1.01°余量的楔形可行域，并与圆域和1500m正信号范围相交；负观测仅按其实际可见性约束更新，不能把一次无信号解释为频道不存在。

## 2. 物理与计时口径

| 参数 | 数值 |
|---|---:|
| 搜索圆半径 | 1800m |
| 源数/频道 | 10--16 / 20个互异频道 |
| 接收半径 | 1000--1500m |
| 定向源 | 180°半平面，朝向未知 |
| 示向误差 | ±1°（实现留±1.01°） |
| 近距离/光学清除半径 | 5m / 20m |
| 移动速度 | 5m/s |
| 测量/切频道 | 5s / 1s |
| 失败/成功光学清除 | 3s / 5s |

虚拟时间按移动、测量、切频道、光学尝试和成功清除累加；程序墙钟时间不属于该口径。

## 3. 25点双环发现与终止

使用25点双环覆盖，覆盖点不因清除而替代或删除。其作用是在最小1000m接收半径和180°定向可见性下保留发现兜底；对已发现但未收敛的定向源，保留无线重捕获和完整正示向光学条带回退。

只有发现16个互异频道时，才停止剩余未知频道的扫描，并转入已知源可靠收尾。若少于16个已见频道，不能按“长时间未发现”“已清10个”或“达到6000s”提前停止。

## 4. 50m认证光学清除

当整个正示向可行多边形都落入半径50m圆时，先在圆心清除；若失败，依次访问半径36m的10个等角环点。对目标距圆心20--50m，最近环点角差至多18°，最坏距离为19.2924m，小于20m清除半径，因此该局部覆盖是确定性的。

最坏的局部中心加环点尝试成本为82.2486s（不含前往圆心的移动，也不是全任务6000s上界）。

## 5. 路线与清除点补测

每次从真实位置，在未访问发现点与已定位清除点上重建开放路线，只执行首节点后重规划。成功清除后，可在实际成功位置对至多2个活跃频道补测；排序用距离、交角、预期可行域收缩和可见性启发式。该排序不签发任何安全证书，且补测不删除覆盖点。

## 6. 代码映射

- `strategies/adaptive_double_ring_clear_probe.py`：最终策略、50m环、补测与16源收尾；
- `strategies/double_ring_optical_clear_probe.py`：25点覆盖和定向条带兜底；
- `strategies/base.py`：状态、行动与接口公共逻辑；
- `geometry.py`、`search_patterns.py`：楔形/包围圆/双环几何；
- `client.py`：重试安全的HTTP与本地接口。

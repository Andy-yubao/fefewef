# 问题 1：有界示向误差下的交会定位

## 1. 问题重述与建模边界

已知多个检测点坐标及同一干扰源在各点的示向度，需在示向误差不超过
\(1^\circ\) 的硬约束下，求出所有与观测相容的位置，计算该定位区域内任意两点的最大距离，
并判断直径等于该最大距离的圆是否必能覆盖定位区域。题目还限定干扰源位于以原点为圆心、
半径 \(R_0=1800\rm\,m\) 的目标圆域。由于同一地点重复测量不改变误差，本模型不把重复读数
视为独立随机样本，而采用有界误差的一致集合模型。

## 2. 单检测点的角扇区约束

设第 \(i\) 个检测点为 \(S_i=(x_i,y_i)\)，示向度为 \(\hat\theta_i\)，误差界为
\(\varepsilon=1^\circ\)。真实方位满足

\[
\theta_i\in[\hat\theta_i-\varepsilon,\hat\theta_i+\varepsilon].
\]

令 \(u(\theta)=(\cos\theta,\sin\theta)\)，二维叉积记为
\(a\times b=a_xb_y-a_yb_x\)。候选点 \(X\) 位于前向角扇区 \(W_i\) 当且仅当

\[
u(\hat\theta_i-\varepsilon)\times(X-S_i)\ge 0,
\qquad
u(\hat\theta_i+\varepsilon)\times(X-S_i)\le 0.
\]

两式均为线性半平面约束。代码直接计算正弦、余弦和叉积，不比较角度数值大小，故
\(0^\circ/360^\circ\) 跨界无需特殊分支。

## 3. 多站交会与凸多边形

全部观测的一致位置集合为

\[
P=\bigcap_{i=1}^{m}W_i.
\]

每个 \(W_i\) 是两个闭半平面的交，因此 \(P\) 为闭凸集；在观测几何能够形成有界、
非退化交集时，\(P\) 是凸多边形。实现令 \(h=2m\)，枚举半平面边界线的两两交点，保留
满足全部约束的点，再取逆时针凸包。该方法复杂度为 \(O(h^3)\)，但 Q1 的观测数很小，
它比引入通用半平面交框架更透明，也便于检查。若法向量不能围成有界区域，程序明确报错，
提示需要增加几何独立的观测。

## 4. 1800 m 目标圆域的独立裁剪

最终定位区域不是无条件的 \(P\)，而是

\[
\Omega=P\cap B(O,R_0),\qquad R_0=1800\rm\,m.
\]

先检查所有 \(P\) 的顶点。由于欧氏范数是凸函数，凸多边形上的最大范数在顶点达到；故若
全部顶点满足 \(\|v\|\le R_0\)，便有 \(P\subseteq B(O,R_0)\)，圆域不生效且
\(\Omega=P\)。只有存在越界顶点时才执行圆域裁剪。

裁剪不把圆近似为多边形。对 \(P\) 的每条边，解析求线段位于圆内的参数区间，得到有效直线段；
同时解析求边与圆的交点，并按极角排序。相邻交点之间的圆周区间若其中点满足 \(P\) 的全部
半平面约束，则该区间是 \(\Omega\) 的有效圆弧。由此边界被精确表示为有限条线段与圆弧。
该结构也覆盖“圆盘完全包含于 \(P\)”这一特殊情形。

## 5. 最终区域直径

定义

\[
D=\max_{x,y\in\Omega}\|x-y\|.
\]

当圆域不生效时，凸多边形的直径由一对顶点达到。由于顶点数小，代码直接枚举顶点对，
复杂度为 \(O(n^2)\)。

当圆域生效时，仅枚举多边形顶点会漏掉圆弧内部的直径端点。对“线段 + 同心圆弧”边界，
以下有限候选足够：

1. 全部线段端点和圆弧端点之间的点对；
2. 对每个端点 \(p\)，若圆上反向点 \(-R_0p/\|p\|\) 位于某有效圆弧，则加入点—弧候选；
3. 对每两条有效圆弧，若存在一对相差 \(\pi\) 的极角，则加入该对径点候选。

理由是：固定圆弧外一点 \(p\) 后，到圆周点的距离只可能在弧端点或 \(-p\) 方向达到最大；
固定一条线段参数时，距离的平方是凸函数，故最大值在端点达到；两条同圆圆弧的内部极值只有
对径点。于是算法解析地覆盖了所有内部极值类型，没有离散误差。

## 6. 直径圆能否保证覆盖

为检验“以定位区域直径为直径所作的圆能否覆盖该区域”，取图 2 所示的三检测点实例。按前述
半平面交算法得到一个六边形定位区域，其直径为

\[
D=43.348530\ \mathrm{m}.
\]

记达到该直径的两个顶点为 \(A\) 和 \(B\)，则 \(|AB|=D\)。假设存在一个直径为 \(D\) 的圆
覆盖整个定位区域，并记其圆心为 \(O\)。由于 \(A,B\) 均在该圆内，必有

\[
D=|AB|\le |AO|+|OB|\le \frac D2+\frac D2=D.
\]

上式两端相等，故两个不等式必须同时取等号，即 \(A,O,B\) 共线且
\(|AO|=|BO|=D/2\)。因此，这个候选圆是唯一的：圆心只能是线段 \(AB\) 的中点，亦即必须直接
以 \(AB\) 为直径作圆，而不能通过平移圆心获得其他候选圆。

本实例中，\(A=V_1\)、\(B=V_4\)，直径圆圆心和半径分别为

\[
O_D=(100.311585,\ 316.213757),\qquad R_D=\frac D2=21.674265\ \mathrm{m}.
\]

计算另外各顶点到 \(O_D\) 的距离可得

\[
|O_DV_2|=30.730658\ \mathrm{m},\qquad
|O_DV_3|=30.975501\ \mathrm{m},
\]

二者均大于 \(R_D\)。所以，以区域直径 \(AB\) 直接作出的圆不能覆盖该六边形；由候选圆的
唯一性可进一步断定，不存在任何直径为 \(D\) 且能覆盖该定位区域的圆。

作为独立的数值复核，枚举由六边形顶点的两点或三点确定的候选圆，得到其最小覆盖圆半径为

\[
R_{\min}=23.098117\ \mathrm{m},\qquad
2R_{\min}=46.196234\ \mathrm{m}>D=43.348530\ \mathrm{m}.
\]

该结果与上述直接证明一致。需要指出的是，平面 Jung 定理对任意直径为 \(D\) 的有界集合给出

\[
R_{\min}\le \frac{D}{\sqrt3},
\qquad
2R_{\min}\le \frac{2D}{\sqrt3}\approx1.155D.
\]

由于 \(2/\sqrt3>1\)，这一普适上界并不保证存在直径为 \(D\) 的覆盖圆。Jung 定理在此用于说明
一般理论边界，而本题六边形的覆盖失败则由直径端点的唯一性论证和最小覆盖圆计算共同确定。
因此，区域直径描述的是区域内最远两点之间的距离，不能一般性地直接作为覆盖该区域之圆的直径。

## 7. 算法流程与代码对应

1. `bearing_wedge_halfplanes`：把每个示向度转成两个半平面；
2. `intersect_halfplanes`：枚举边界交点、可行性筛选并取凸包，得到 \(P\)；
3. `clip_polygon_with_disk`：先判定圆域是否生效，必要时解析生成线段—圆弧边界；
4. `polygon_diameter` 或 `clipped_region_diameter`：分别处理纯多边形与含圆弧情形；
5. `solve_q1`：返回 \(P\)、\(\Omega\) 的边界信息和直径端点。

全部数值容差集中在 `GeometryTolerance`；角度输入为度，内部统一转为弧度。核心模块仅用 Python
标准库。Isler–Bajcsy 与 Calafiore 所支撑的内容及不可外推部分见 `literature_mapping.md`。

# Q1 事实库（论文入口）

更新日期：2026-09-13（Asia/Shanghai）

## 当前结论

Q1采用有界误差的一致集合模型：每次±1°示向度形成两个闭半平面，多站可行域为其交集，再与半径1800m目标圆精确相交。最终报告的定位不确定性取裁剪后区域的欧氏直径。

区域直径不能一般地直接作为覆盖该区域的最小圆直径。三站反例中，定位多边形直径为43.348530m，而最小覆盖圆直径为46.196234m。

阅读顺序：`current_model.md`、`performance.md`、`history.md`，再回溯本文件的代码与图件索引。

## 可写入论文的结论

- 同地点重复测量不产生独立新误差样本，故不能按独立随机噪声把误差缩小；模型保留全部与观测相容的位置。
- 圆域裁剪含圆弧时，直径端点可能位于圆弧内部；仅枚举多边形顶点并不充分。
- 直径端点确定后，若存在直径等于区域直径的覆盖圆，其圆心被两端点唯一确定为中点；反例的其他顶点落在该圆外，因此不存在同直径的覆盖圆。

## 不可越界

- ±1°是硬误差界，不应写成独立高斯噪声或置信区间。
- Q1的解析算法针对少量观测站；其 (O(h^3)) 半平面边界枚举不是大规模通用半平面交算法的效率承诺。
- Jung定理只给出 (2R_{\min}\le2D/\sqrt3)，不推出存在直径为D的覆盖圆。
